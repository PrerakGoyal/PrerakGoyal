## 📌 Featured Project: Markdown Portfolio Generator

<p align="center">
  <img src="https://img.shields.io/badge/Python-CLI_Tool-blue?style=for-the-badge&logo=python&logoColor=white" />
  <img src="https://img.shields.io/badge/Markdown-Static_Site-orange?style=for-the-badge&logo=markdown&logoColor=white" />
</p>

A **Python-based static site generator** that converts a folder of content files into a clean, responsive HTML portfolio website.

---

### ✨ Key Features

- 📄 Converts **Markdown** files into static HTML pages
- 🧾 Supports **YAML-style frontmatter**
- 🗂️ Auto-generates:
  - Individual project pages
  - Portfolio index page
- 🎨 Responsive UI with modern CSS (no frameworks)
- 🖥️ CLI-based usage
- 🧱 Modular and extensible architecture
- 🪟 Cross-platform (Windows, Linux, macOS)
